# uvlhub.io

Repository of feature models in UVL format integrated with Zenodo and flamapy following Open Science principles - Developed by DiversoLab

## Official documentation

You can consult the official documentation of the project at [docs.uvlhub.io](https://docs.uvlhub.io/)

## Email verification

New accounts must verify their email address before uploading datasets. Configure
`MAIL_SERVER`, `MAIL_PORT`, `MAIL_USE_TLS`, `MAIL_USERNAME`, `MAIL_PASSWORD`,
and `MAIL_DEFAULT_SENDER` in the application environment to send verification
messages. Verification links expire after one hour by default; override this
with `EMAIL_VERIFICATION_MAX_AGE` (seconds).
